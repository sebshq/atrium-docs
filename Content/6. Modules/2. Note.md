# Note | Any note, *right where you want it.*

A Note card edits any note in place: a reading list, a recipe, the chapter you're writing.

## Next and previous | Flip *through the folder.*

<video src="/_assets/guide/note-next.mp4" poster="/_assets/guide/note-next.jpg"></video>

With the card picked out, <kbd>]</kbd> and <kbd>[</kbd> show the next and previous file in the file explorer's order. **Next file** and **Previous file** are also behind the card's ⋯, on its right-click menu and in the command palette.
